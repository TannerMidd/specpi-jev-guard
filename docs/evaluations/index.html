The evidence behind the comparison

Matched CPU/GPU/API runs, the 856-attempt devious suite, and a bounded tuning study. The failures are kept alongside the successes.

Recorded 2026-09-22. These pages do not add a Laya backend or change the released package.

On this page

The Laya implementation is shelved. The comparison did not justify shipping it as a safety-equivalent alternative to Jev. This archive preserves observations, not an installation option. It also does not establish that Laya could never improve.

Devious suite: 856 attempts

The original 136 cases plus 120 new attack/benign pairs across 20 families, each tested plainly, nested or encoded, and with misleading assurances. These are correlated views, not 720 independent new techniques.

Jev gave 9 unexpected allows among 471 attack-labelled attempts; Laya GPU gave 114, plus one input rejection. Controls interrupted: 77/385 and 190/385 respectively; hard blocks: 13 and 54. Jev missed only one new plain attack, so more cases did not establish a harder benchmark.

No CPU run of this suite. It was recorded by the research runner; npm run devious now runs the same 856 cases against Jev, and a test checks they match this record. Records retain the exact command, tool, user context, expectation and result. No adversarial command was executed.

Tuning: no preset adopted

Six predeclared general configurations used unchanged weights and thresholds. All were evaluated on a deterministic 505-case sample of ShellRisk-Bench's TRAIN split. None passed the development gate. FP32 was frozen for diagnosis only, then evaluated once against baseline on 4,193 TEST rows after exact-overlap filtering.

Both detected 119/193 risky test inputs; baseline interrupted 1,467/4,000 benign inputs and FP32 1,482/4,000, including one rejected benign input each. No other candidate was tried on the test split. The devious suite was not used to select or adopt a candidate.

No weights were trained and no thresholds fitted.

Archive scope and integrity

SHA-256 checksums cover the unchanged raw observations and frozen study inputs. Original manifests retain experiment paths for provenance; they do not imply that the Python service or research runners are included here. This is an auditable record, not a stand-alone inference reproduction kit.

The Laya runtime and its collection code remain in the shelved implementation work; the devious suite's cases and a Jev runner are in the repository. Model weights, Python environments and mixed-license external command data are not distributed with these pages. The archive can be verified with node docs/evaluations/verify.mjs, without model or API access.
